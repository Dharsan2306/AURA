# AURA
AURA – Maison de Parfum: A luxury haute parfumerie single-page web app crafted in pure vanilla HTML5, CSS3 &amp; JS. Features an animated canvas atmosphere, 15-scent catalog with fragrance pyramids, bespoke scent studio with live SVG bottle engraving, curated gifting suite (Couples Edition), and a full luxury checkout with custom gift wrapping.
